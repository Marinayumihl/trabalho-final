# Portfólio - Marina Yumi

Portfólio pessoal desenvolvido em **React** com o objetivo de apresentar meus projetos, habilidades e conhecimentos adquiridos durante minha formação em desenvolvimento front-end.

O projeto possui uma interface responsiva, navegação entre seções e apresentação de alguns dos principais projetos desenvolvidos durante o curso.

## Funcionalidades

- Página inicial com apresentação
- Seção "Sobre mim"
- Exibição de projetos desenvolvidos
- Lista de habilidades e tecnologias
- Links para os repositórios dos projetos
- Área de contato
- Menu responsivo para dispositivos móveis
- Layout adaptado para diferentes tamanhos de tela

## Projetos apresentados

### Agência Criativa Web

Site institucional responsivo desenvolvido para uma agência criativa, utilizando HTML, CSS e SASS.

### Catálogo de Livros

Aplicação desenvolvida com React e TypeScript para gerenciamento de livros, utilizando integração com API REST.

### Todo React Avançado

Gerenciador de tarefas desenvolvido em React utilizando Context API, hooks, filtros e persistência de dados com localStorage.

## Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Marinayumihl/portfolio-react.git
```

### 2. Entre na pasta do projeto

```bash
cd portfolio-react
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Após executar o comando, o Vite exibirá no terminal o endereço local da aplicação.

Normalmente:

```text
http://localhost:5173
```

Abra esse endereço no navegador para visualizar o portfólio.

## Verificação do código

Para executar o ESLint e verificar possíveis problemas no código:

```bash
npm run lint
```

## Build de produção

Para gerar a versão otimizada para produção:

```bash
npm run build
```

Após a execução, os arquivos de produção serão gerados na pasta `dist`.
